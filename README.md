# Subham Agrawal: portfolio

Static site deployed on Vercel. `index.html` is the professional page, `life.html` is "Off the clock" (hobbies). Both share `style.css`.

- Resume: replace `Subham_Agrawal_Resume.pdf`.
- Photos: upload JPGs to `photos/` named `1.jpg`, `2.jpg`, ... up to `12.jpg`. Missing numbers are skipped. Keep each under ~500 KB.
- Treks and trips: copy the `row` block in the `#outdoors` section of `life.html`.
